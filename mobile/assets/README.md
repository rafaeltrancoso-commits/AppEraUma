# Assets oficiais do EraUma

Esta pasta esta preparada para receber os arquivos finais separados da identidade visual aprovada.

Arquivos esperados antes do APK Beta:

- `app-icon.png`: composicao quadrada do icone com crianca, livro, estrelas e fundo claro. Nao incluir texto auxiliar, Android, iOS, telefone ou slogan fora do icone.
- `adaptive-icon-foreground.png`: foreground do icone Android respeitando safe area.
- `splash.png`: crianca lendo "ERA UMA VEZ", marca EraUma, slogan "Momentos que viram historias" e estrelas/nuvens discretas em fundo claro/quente. Nao incluir moldura de telefone.
- `favicon.png`: versao reduzida para Web, se aplicavel.

O `app.json` so deve apontar para esses arquivos quando eles existirem como imagens finais. Nao extrair automaticamente de screenshot ou mockup de baixa qualidade.
